# Mighty Mouse v0.2.5

Mighty Mouse v0.2.5 hardens MCP dependency resolution against an upstream
`pydantic-settings` warning during server startup.

## Release changes

- Capped `pydantic-settings` below `2.15` across runtime and development
  dependency metadata.
- Aligned core and MCP package versions at `0.2.5`.
- Preserved existing MCP server behavior without adding a local regression test
  for dependency-owned warning behavior.

## Limits

Warning-producing `Settings.lifespan` field remains upstream-owned by MCP and
`pydantic-settings`. Future upstream compatibility changes may allow removal
of dependency cap.
